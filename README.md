# 몽글터미널

여러 터미널을 그룹·분할·탭으로 정리하고, 휴대폰에서도 이어 쓰는 Windows 터미널입니다.

## 다운로드

**[최신 버전 받기](https://github.com/bokjk/mongle-terminal-releases/releases/latest)** · Windows 11 x64 미리보기

- 일반 설치: `MongleTerminal-Setup-<버전>-x64.exe`
- 압축 실행: `MongleTerminal-<버전>-x64.zip` 전체를 풀고 `MongleTerminal.exe` 실행
- 파일 확인: 같은 Release의 `SHA256SUMS.txt`

코드 서명 없는 미리보기라 Windows SmartScreen 안내가 표시될 수 있습니다. 이 저장소에서 받은 파일인지 확인해 주세요. 현재 사용자용 설치이며 관리자 권한은 필요하지 않습니다.

## 0.3.6의 Git 변경 보기

파일 탐색기 위의 **파일 / Git**으로 현재 터미널 폴더의 변경을 확인합니다. 충돌·스테이징·작업 폴더 변경·새 파일을 나누고 브랜치와 변경 파일 개수를 표시합니다. 파일 트리에도 상태 색과 문자를 표시하며, 변경된 하위 파일이 있는 폴더에는 점을 붙입니다.

수정 M은 황갈색, 추가 A·새 파일 ?는 초록색, 삭제 D·충돌 U는 빨간색, 이름 변경 R은 보라색입니다. 패널이 열려 있으면 5초 간격으로 갱신하며 펼친 폴더를 유지합니다. 선택한 PC에 Git이 설치되어 있어야 하고 파일 선택은 현재 내용의 읽기 전용 미리보기입니다.

## 탭과 분할

왼쪽 아래 생성 버튼 이름을 **새 분할 → 새 터미널**로 정리했습니다. 클릭으로 셸·시작 폴더를 선택하고 드래그로 분할하는 동작은 유지합니다.

![영역별 터미널 탭과 왼쪽 아래 도구](docs/assets/desktop.png)

격리된 예시 프로젝트를 실제 앱의 웹 화면으로 촬영했습니다. 화면의 예시 테스트 결과는 몽글터미널 전체 회귀 결과와 구분합니다.

- 각 분할 영역 안에서 터미널을 탭으로 전환합니다. 마지막 탭 바로 뒤 **+** 또는 `Ctrl+Shift+T`로 새 탭을 열고 `Ctrl+Tab` / `Ctrl+Shift+Tab`으로 이동합니다.
- **탭 제목**을 자기 영역 가장자리로 끌면 탭 하나를 새 분할로 떼어냅니다. 원래 영역에 탭이 두 개 이상 있어야 합니다. 다른 영역의 가장자리는 분할, 가운데는 그 영역의 탭으로 합치기입니다.
- **왼쪽 점 손잡이**는 모든 탭을 포함한 영역 전체를 옮깁니다. 다른 영역 가운데에서는 두 영역을 교환하며 Esc로 취소합니다.
- PC의 **새 터미널·파일 탐색기·설정**은 왼쪽 아래에 있습니다. 별도 상단 도구줄을 없애 작업 공간을 넓혔습니다.

탭 전환·재배치는 실행 중인 셸을 유지합니다. 탭의 X는 확인 후 해당 작업을 종료하고 닫습니다.

## 기존 사용자 업데이트

**0.3.0 이하 사용자는 0.3.1 이상 설치 파일을 한 번 직접 설치해야 합니다.** 작업을 저장하고 앱 메뉴의 **완전 종료…**를 선택한 뒤 설치하세요. 창 닫기만으로는 실행부가 종료되지 않습니다. 사용자 데이터는 업데이트 과정에서 자동 삭제하지 않습니다.

0.3.1부터 NSIS 설치본은 이 저장소의 새 안정 버전을 자동 확인·다운로드합니다. **설정 → 앱 업데이트**에서 직접 확인할 수도 있습니다. 다운로드가 끝나면 사용자가 **설치 후 다시 시작**을 확인하고 현재 PC의 작업을 정상 종료한 뒤 적용합니다. ZIP은 수동 교체 대상입니다. 실제 구버전 NSIS 설치본의 자동 교체·재실행·복원은 추가 검증 대상입니다.

## 처음 사용하기

1. **새 터미널**에서 셸과 작업 폴더를 선택합니다. 영역의 **+**로 탭을 추가하고 분할 버튼이나 왼쪽 아래 **새 터미널**로 화면을 나눕니다.
2. 탭 제목을 가장자리로 끌어 분리하거나 점 손잡이로 영역 전체를 옮깁니다. 터미널 내용을 눌러 입력합니다.
3. 원격 접속은 작업 PC에서 Tailscale을 준비하고 **설정 → 원격 연결**을 켠 뒤 QR코드·주소로 접속한 기기를 승인합니다. 작업 PC가 켜져 있어야 합니다.

자세한 사용자 안내와 제3자 소프트웨어 고지는 배포본의 `resources/hostbundle/docs`에 포함되어 있습니다.

이 저장소에는 배포 파일과 안내만 게시합니다. 몽글터미널 소스 저장소는 비공개이며 프로젝트 자체의 오픈소스 라이선스는 아직 정하지 않았습니다. 제3자 구성요소의 라이선스는 배포본에 동봉합니다.
